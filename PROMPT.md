Задача: создать production-ready веб-приложение для проектирования электрощитов квартиры/дома, включая резервное питание (АВР, генератор, инвертор, АКБ, солнечные панели), с визуальным редактором и расчётом ориентировочной стоимости в сборе (только материалы, без работы).

- Frontend: React 18 + TypeScript + Vite, dnd-kit (drag&drop), Zustand (state + undo/redo), React Flow (однолинейные схемы), Tailwind. Типы API генерируются из OpenAPI (openapi-typescript).
- Экспорт: WeasyPrint (PDF), openpyxl (XLSX).

- UI: русский/украинский (i18n), валюта UAH, цены с НДС.

[ОБЩИЕ ПАРАМЕТРЫ]
- Сети 1ф 230В и 3ф 400В. Системы заземления TN-C-S / TN-S / TT.
- Пользователи: регистрация/логин, проекты принадлежат владельцу. Admin для каталога.

[ФУНКЦИОНАЛ]
1. Проект: объект (квартира/дом), ввод (1ф/3ф, номинал вводного автомата, система заземления), несколько щитов (ГРЩ, этажные, щит резерва/АВР, DC-бокс) со связями «щит → щит».

2. Группы потребителей: название, помещение, тип (освещение, розетки, кухня, плита, бойлер, кондиционер, тёплый пол, стиралка и т.д.), мощность, cos φ, фаза, длина линии, признак «резервируемая».
   Автоподбор: номинал и характеристика автомата (B/C), сечение Cu-кабеля по току и падению напряжения (≤3–5%), УЗО/дифавтомат (30 мА для розеток/влажных зон), группировка под УЗО.

3. Элементы: вводной автомат/рубильник, пожарное УЗО 100–300 мА, реле напряжения, УЗИП (тип 1+2 / 2), счётчик, контакторы, таймеры, реле контроля фаз, шины N/PE, гребёнки, DIN-рейки, заглушки, маркировка.

4. Балансировка фаз (3ф), подсветка перекоса >15%.

5. Расчётная мощность с Кс по типам групп, проверка селективности по номиналам.

6. Визуальный редактор:
- Вид «Щит»: корпус в масштабе, N рядов DIN × M модулей (1 модуль = 17.5 мм), плюс монтажная панель для недин-оборудования (АВР на контакторах, клеммники). Подбор корпуса по модулям с резервом 20%, IP, внутренний или навесной.
- Палитра из каталога с фильтрами (тип, бренд, номинал, полюса).
- Drag&drop: из палитры на рейку, между рейками и щитами, удаление в корзину. Снап к модулям, подсветка допустимой позиции, запрет коллизий и выхода за край рейки. Мульти-выделение, копирование, zoom/pan.
- Элемент привязан к группе, подпись группы видна на элементе. Неразмещённые автоматы показаны отдельным списком.
- «Автокомпоновка» (ввод → реле/УЗИП → УЗО с группами) с последующей ручной правкой.
- Вид «Однолинейная схема» (React Flow) синхронизирован с видом щита двусторонне.
- Undo/redo, автосохранение (debounce PATCH), версии компоновки. Серверная валидация (ширина, коллизии, совместимость).
- Мгновенный пересчёт BOM и цены. Экспорт SVG/PNG/PDF и наклеек маркировки.
- Адаптив для планшета, на мобильном только просмотр.

7. Спецификация (BOM): позиция, бренд, артикул, количество, цена, сумма. Итоги отдельными строками «Щиты», «Солнечная система» и общий. Экспорт PDF/XLSX. В PDF включить однолинейную схему и вид щита.

8. Каталог: Brand, Category, Product (артикул, тип, номинал, полюса, характеристика, ток утечки, тип УЗО AC/A, модульность, габариты, электрические параметры JSON, цена, дата цены). Импорт/экспорт CSV. Ценовые уровни: эконом / средний / премиум (ABB, Schneider, Eaton, Hager, IEK, E.Next) с подбором аналогов. Seed: ~150 типовых позиций, включая инверторы, АКБ, панели, DC-защиту.

9. Резервное питание:
- Источники: сеть, генератор 1ф/3ф (кВА, cos φ 0.8, автозапуск), инвертор/ИБП (гибридный, off-grid, on-grid; 1ф/3ф, параллельные инверторы; мощность, байпас), АКБ.
- Сценарии (шаблоны): сеть + генератор через АВР; сеть + инвертор; сеть + инвертор + генератор (приоритеты); ручной переключатель I-0-II; «3ф сеть + 1ф генератор» (одна фаза или объединение фаз на резервной шине с блокировкой); «1ф сеть + 1ф генератор».
- Разделение нагрузки на резервируемую и нерезервируемую. Проверка мощности источника (Кс, пусковые токи, перекос 3ф генератора). Автономия от АКБ.
- Подбор: АВР на контакторах (механическая + электрическая блокировка) или модульный, автоматы входа/выхода инвертора и генератора, УЗИП, коммутация N по системе заземления.
- Валидация безопасности: запрет параллели генератора с сетью без блокировки, корректная коммутация N (4п для 3ф), RCD после инвертора с учётом его N-PE.

10. Солнечные панели (PV):
- Ввод: модель панели (Pmax, Voc, Isc, Vmp, Imp, температурный коэффициент Voc), количество, ориентация, угол.
- Конфигуратор строк на MPPT. Проверки: Voc при Tmin (по умолчанию −20 °C) ≤ Vmax MPPT; Vmp в диапазоне MPPT; Isc ≤ Imax входа; DC/AC (подсветка, если > 1.3).
- DC-бокс как отдельный щит: предохранители gPV (если строк > 2), DC-разъединитель, DC-УЗИП (Ucpv ≥ Voc max), MC4. Кабель PV 4/6 мм² по току и падению ≤1–2%.
- АКБ: LiFePO4/AGM, напряжение, кВт·ч, DC-защита по току инвертора.
- AC: автомат на выходе инвертора, УЗИП, двунаправленный учёт / «зелёный тариф» опционально, ограничение экспорта.
- Ориентировочная выработка кВт·ч/год: упрощённая модель или PVGIS API (опционально, с кешем).
